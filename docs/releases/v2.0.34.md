# Portal v2.0.34

Portal v2.0.34 automatically discovers companion web services opened by an
already-forwarded remote process.

## Related-process port discovery

Remote development tools often serve a primary page on a stable port while
embedding an iframe, API, or helper service on a random Linux ephemeral port.
Portal now correlates loopback listeners through their socket inodes and
automatically forwards ephemeral companions owned by the same process. This
keeps unrelated ephemeral listeners filtered while making multi-port web tools
work without maintaining a random-port allowlist.

Each box also has a new **Discovery Settings** panel. Same-process discovery is
always enabled; an optional setting broadens discovery to helper processes in
the same Linux process group. The broader setting is disabled by default and
applies live without reconnecting the box.

Process-based expansion never bypasses explicit port denies. Same-number local
mappings remain preferred so iframe and browser origins continue to match the
ports advertised by the remote service.
