# Portal v2.0.32

Portal v2.0.32 adopts native Liquid Glass throughout the functional layer of
the SwiftUI macOS app.

## Native Liquid Glass controls

Primary and secondary actions now use the system `glassProminent` and `glass`
button styles on macOS 26. The upload destination and remote-folder controls
receive the same native treatment, while the custom file drop target uses a
responsive, tinted glass effect during pointer and drag interactions.

Custom effects share a `GlassEffectContainer` for efficient rendering and the
system's native blending behavior. Content cards continue to use standard
materials to preserve a clear hierarchy and avoid overusing glass.

Portal still supports macOS 13 and later. Earlier systems automatically retain
native bordered controls and the existing drop-target appearance.
