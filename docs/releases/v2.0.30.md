# Portal v2.0.30

Portal v2.0.30 improves upload completion details in the native macOS app.

## Per-item uploaded paths

A successful multi-item upload now lists the complete remote target path for
every file or folder selected by the user instead of showing only the shared
destination directory. For example:

```text
Uploaded 2 items
~/tmp/portal/report.csv
~/tmp/portal/screenshots
```

The paths use monospaced text, remain selectable for copying, wrap rather than
truncate, preserve selection order, and correctly join root or trailing-slash
destinations.
