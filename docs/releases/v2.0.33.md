# Portal v2.0.33

Portal v2.0.33 restores credential approval for remote `sudo -A` requests.

## Fixed Touch ID and password prompts

The native SwiftUI application linked Portal's Rust implementation as a static
archive, but the final executable did not preserve the archive's transitive
`LocalAuthentication.framework` dependency. As a result, the credential task
panicked while resolving `LAContext`, before Portal could show either Touch ID
or its password-entry dialog.

The final Swift executable now links Local Authentication explicitly. Builds
verify the framework load command, and the release process executes the signed
credential initialization path before notarization so the same omission cannot
ship again.
