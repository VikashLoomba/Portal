portal v0.6.0 completes the clipboard story: **copy now works from the dev
box**. `pbcopy`, `xclip`, `wl-copy`, and `xsel` were broken (or silently
discarded data) over ssh; they now land on your Mac clipboard — gated,
audited, and visibly.

## New: dev box → Mac clipboard writes

`echo url | pbcopy`, `git diff | xclip -sel c`, tmux `copy-pipe`, and nvim's
clipboard provider all just work over plain ssh. Shims v8 add `wl-copy`,
`pbcopy`, `pbpaste`, and `xsel`, and rewrite `xclip` as a real argv parser
(prefix abbreviations like `-sel c` included). X primary and clipboard both
map to the one Mac pasteboard; `image/png` writes are supported; other image
types fall through untouched (format honesty). `wl-copy --clear` and empty
writes clear the pasteboard, matching each tool's native semantics.

**A write never silently succeeds-and-discards.** If portal can't deliver,
the shim falls through to a real binary when one exists — with stdin
faithfully preserved via a 0600 buffer — or fails loudly on stderr with
exit 1. (Previously, `xclip -i` on a binary-less box exited 0 and dropped
your data.)

## Security posture: visibility, not absence

Remote clipboard writes are the OSC 52 attack surface done accountably —
which is why terminal OSC 52 stays disabled and this path exists instead:

- **Native banner on every remote write** — "Clipboard set from `<host>`"
  with kind + size (never content, so a copied secret is not echoed on
  screen). Bursts coalesce (5s window) with a trailing summary; the banner
  deliberately bypasses the `notify` feature gate so it cannot be silenced
  by accident.
- **Gated + audited**: new `clip-write` capability (default on, `portal
  features clip-write off` to disable); every write and every denial
  (`disabled` / `oversize` / `badsha` / `shamismatch` / `inflight`) is an
  audit-log line.
- **Content-addressed integrity**: the Mac reconstructs the pull path from a
  validated SHA (never a wire path), re-verifies bytes before touching the
  pasteboard, and refuses when multiple portal clients are connected.
- Size caps (8 MiB image / 1 MiB text) enforced on both ends; the pasteboard
  is set **before** the box sees `ok`.

## Also

- New `clipwrite@1` service rides the existing Hello/HelloAck negotiation —
  **no ProtoVersion bump**; old Mac + new agent degrades to a clean
  fall-through. `docs/wire.cddl` gains the frames.
- `portal doctor` checks the four new shims, the `clip copy` verb, and the
  Mac-side `clip-write` gate (no destructive write smoke by default).
- All shim scripts are POSIX sh, tested under dash; deployed boxes converge
  to v8 automatically on the next daemon reconnect — no reinstall.
- `DESIGN-clipboard-write-interception.md` documents the full contract,
  including the honest threat-model residuals (§7.3).
