# Portal v2.0.31

Portal v2.0.31 corrects the default remote upload destination on Linux.

## Correct Linux temporary directory

Files and folders now upload to `/tmp/portal/<item>` by default. Earlier
releases incorrectly used `~/tmp/portal/<item>`, which is a directory beneath
the remote user's home rather than Linux's system temporary directory.

Custom destinations selected with the remote folder browser are unchanged.
When `/tmp/portal` does not exist yet, the destination picker starts in `/tmp`;
the upload itself creates `/tmp/portal` automatically.
